About TaskFlow

TaskFlow is a simple, secure to-do list web app built as the first project of the DecodeLabs Python Programming training.

How it works

  • Python lists and loops handle the task logic.
  • Flask connects the Python code to the web pages.
  • Firebase Authentication handles sign up and login.
  • Firestore stores each user's tasks permanently.

Built with free, open-source tools

Python, Flask, Firebase (free plan), HTML and CSS.
